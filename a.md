| Paper | Venue / Year | Method used (LVIS NOD setting) | LVIS NOD results (LVIS v1.0 val, mAP@[0.5:0.95]) | Main limitations in this setting |
| --- | --- | --- | --- | --- |
| **Enhancing Novel Object Detection via Cooperative Foundational Models (CoFM)** | WACV 2025 | Training-free **cooperative** pipeline that combines a closed-set detector (e.g., Mask R-CNN / GDINO) with foundational models (CLIP / SigLIP, SAM). Proposals from GDINO and open-set Mask R-CNN are merged, refined using SAM masks, and re-scored with CLIP/SigLIP plus specialized modules (e.g., similarity-aware scoring and region refinement) for better novel object detection. | **All:** 19.33; **Known:** 42.08; **Novel:** 17.42 | High computational cost at inference because multiple large models (detector + SAM + VLM) run jointly; this leads to slow runtime and heavy memory usage. Potential data-leakage risk if web-scale pre-training has seen similar images. Focuses mainly on bounding-box NOD (segmentation benefits not fully exploited) and assumes access to strong VLMs, which may not always be available. |
| **Learning to Discover and Detect Objects (RNCDL)** | NeurIPS 2022 | Two-stage **novel class discovery and localization** detector. Uses supervised training on labeled COCO (known classes) plus a discovery phase on unlabeled images (COCO + LVIS) with long-tail constraints. Region proposals are generated by an RPN and the model learns to assign novel labels via clustering and pseudo-labeling, producing a full detection model for both known and novel classes. | **All:** 6.92; **Known:** 25.00; **Novel:** 5.42 | Complex multi-stage training pipeline that requires careful hyperparameter tuning and substantial training cost. Despite this, performance is still significantly below modern foundational-model-based approaches (low novel mAP). Not training-free: full detector training is required, and the method does not exploit strong vision–language priors, limiting generalization to many LVIS novel categories. |
| **Open-World Semi-Supervised Learning (ORCA)** | ICLR 2022 | Method originally designed for open-world semi-supervised **classification**. Uses labeled data for seen classes and an unlabeled pool containing both seen and unseen classes with an uncertainty-adaptive margin loss. For LVIS NOD it is used as a novel-class discovery backbone: pseudo-labels produced by ORCA are plugged into the same COCO+LVIS detection pipeline. | **All:** 2.03; **Known:** 20.57; **Novel:** 0.49 | Primarily a classification method, not tailored for dense detection. When adapted to LVIS NOD, novel mAP is extremely low, showing limited ability to localize and recognize many LVIS novel classes. Still requires supervised + semi-supervised training and is not training-free. It also does not use modern VLM / open-set detection modules, so semantic generalization in the detection setting is weak. |
| **A Unified Objective for Novel Class Discovery (UNO)** | ICCV 2021 | Classic **novel class discovery** method with a single unified objective for labeled and unlabeled data. Uses multi-view self-labeling: pseudo-labels for unlabeled (novel) samples are treated as targets so that a single cross-entropy objective is applied over both known and pseudo-labeled novel samples. Originally proposed for image-level NCD, later plugged into the LVIS NOD pipeline as a backbone. | **All:** 2.18; **Known:** 21.09; **Novel:** 0.61 | Very effective on NCD classification benchmarks, but not specialized for dense object detection. On LVIS NOD it yields very low novel mAP and is outperformed by RNCDL and CoFM. Requires supervised training on known classes and pseudo-label training on unlabeled data, and does not use strong vision–language priors or open-set detectors, limiting its performance on large-scale novel categories. |
| **Unsupervised Discovery of the Long-Tail in Instance Segmentation Using Hierarchical Self-Supervision (Weng et al.)** | CVPR 2021 | Fully unsupervised long-tail discovery approach for instance segmentation. Learns embeddings for instance masks using hierarchical self-supervision and clustering, so that fine-grained long-tail categories emerge without labels. This representation is used as a baseline for novel / long-tail category discovery and adapted to LVIS NOD evaluation. | **All:** 1.62; **Known:** 17.85; **Novel:** 0.27 | Assumes access to high-quality instance masks and relies on heavy offline clustering, making it less practical for pure detection pipelines. When evaluated on LVIS NOD, novel mAP is extremely low, indicating poor performance for large-scale novel object detection. It is not optimized for bounding-box detection and does not use modern VLMs or open-set detection, so semantic generalization to many unseen LVIS categories is limited. |
